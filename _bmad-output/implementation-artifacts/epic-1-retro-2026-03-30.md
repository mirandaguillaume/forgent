# Epic 1 Retrospective — Core Doctor Analysis

**Date:** 2026-03-30
**Epic:** 1 — Core Doctor Analysis
**Stories:** 6/6 done
**Facilitator:** Bob (Scrum Master)

## What Went Well

- **ADR-driven architecture** — 9 ADRs documented, decisions from party mode sessions all confirmed in implementation
- **Story-by-story progression** — each story built on the previous without refactoring
- **Engineering spike first** — de-risked the biggest assumption (local LLM quality) before committing
- **Adversarial code reviews** — 3-layer reviews (Blind Hunter + Edge Case Hunter + Acceptance Auditor) found real bugs every time
- **Real testdata corpus** — 22 agent files scraped from public GitHub, tests against reality not fixtures
- **Working demo** — `forgent doctor` runs end-to-end with Ollama local AND OpenRouter cloud

## What Was Difficult

- **Frontmatter parsing** — yaml.v3 too strict for real Claude agent files (unquoted colons in long descriptions). Workaround: text-based fallback in Detect. Not a real solution.
- **Spike timeout** — 22 files x 4 models exceeded 900s test timeout. Accepted 5-file results — sufficient for spike, not for production validation.
- **Scope creep** — added 7 recommendation categories (12 total vs planned 5) during implementation. Good for product, bad for predictability.
- **OpenRouter timeout** — existing OpenRouter provider has no timeout, blocks indefinitely on large files.
