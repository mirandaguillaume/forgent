Story 5-3 expanded this to 60 files (30 Claude + 30 Copilot).

### 3. Reproducible Methodology
All experiments use deterministic seeding (seed=42), bootstrap CI (1000 resamples, 95% confidence), and documented methodology (METHODOLOGY.md). A third party can reproduce results with `forgent-bench --level experiment`.

### 4. Auto-Discovery Patterns
InstructionBench (5-1) discovers corpus files automatically. Format Fidelity (5-3) discovers parsers via `RegisteredFormats()`. Adding a new parser or test file requires zero changes to framework code. CONTRIBUTING.md codifies this for external contributors.

## What Didn't Go Well

### 1. Experiment Results Do Not Support Thesis
The runtime-vs-text experiment was run with haiku (390 runs). Results: text outperforms runtime on all metrics (completion: 15% vs 9%, ordering: 14% vs 9%, guardrails: 13% vs 6%). Only 2/13 tasks complete at all. Runtime detection rate: 0%.

**Root cause:** Haiku is too small for most experiment tasks. 85% of tasks fail under BOTH conditions. Runtime makes 3 LLM calls per task vs 1 for text, multiplying failure probability. The framework is validated (it produces measurable, reproducible results), but the evidence for "+20-33% structural enforcement" is not yet generated.

**Action needed:** Re-run experiment with Sonnet or Opus once API credits are available. Consider reducing task difficulty or adding simpler tasks that smaller models can complete. As of 2026-04-15, Anthropic API credits are exhausted — blocking both experiment re-runs and LLM-dependent test execution.

## Lessons Learned

1. **Framework ≠ Evidence.** Building a benchmark framework (tests pass, mocks work) is not the same as generating evidence. The experiment must be run with a capable model to produce the data that matters.

2. **Model capability matters for experiment design.** Tasks designed for Sonnet/Opus fail completely on Haiku. Future experiments should include difficulty tiers or minimum model requirements.

3. **Corpus-first is the right strategy.** Real files, reusable across stories, deterministic. This pattern should be carried forward.

4. **Auto-discovery reduces contributor friction.** `init()` + testdata = automatic inclusion. Document this pattern for every extensibility point.

5. **Deferred work needs active triage.** Accumulating items without review leads to lost context. Schedule periodic triage sessions.
