## THE THINGS THAT MADE US SMILE

**The equivalence test.** 22 agent files (12 Claude, 10 Copilot), deterministic mock provider, category-by-category comparison. The old hand-wired `analyzeFile()` and the new DAG-based `analyzeFile()` produce identical results. This is the kind of test that lets you sleep at night.

**The decorator stack.** `wrapWithPanic -> wrapWithRetry -> wrapWithDebug` — three independent concerns, cleanly composed. Panic recovery is innermost (catches panics in the original Run). Retry is next (sees the panic-safe version, skips further retries on deterministic panics). Debug is outermost (measures total wall time including all retry attempts). Testable via `io.Writer` injection. Chef's kiss.

**The context fix.** Code review caught `context.Background()` hardcoded in `analyzeFile`. Before the fix, pressing Ctrl-C during a doctor run would... do nothing. The LLM call would keep running for up to 120 seconds. Now `cmd.Context()` propagates through the full call chain, and cancellation actually works.

**The cache fix.** If an agent file was perfectly clean (zero LLM findings), the cache never saved the result. Every subsequent run re-invoked the LLM. For the *healthiest* files. The ones that need analysis the *least*. Fixed: cache saves regardless of finding count.

**The scoring fix.** `scoreOrchestration` only gave full marks to `sequential` orchestration. `parallel` — an equally valid pipeline pattern — was penalized. Historical bias from when sequential was the only pattern. Now both get equal credit.

## THE FOOTNOTE: FR50 IS 90% DONE

**What FR50 says:** "Doctor IS a Forgent runtime agent defined in YAML, executed by the real DAG engine."

**What we shipped:** Doctor is executed by the real DAG engine. Check. But `BuildDAG()` is hardcoded Go structs. The embedded YAML specs (`SkillSpecs()`, `AgentSpec()`) exist, are tested, and are synced with canonical files via `TestEmbedSync` — but they're never called from the production code path.

**The decision was deliberate.** During the Story 4-2 review, Guillaume chose "defer to future story" over "retrofit now." The reasoning: the embedded specs are the contract definition, the Go structs implement that contract, and `TestEmbedSync` keeps them in sync. Full YAML-driven DAG construction (where `BuildDAG()` calls `internal/yaml/` to parse the specs and generates nodes from them) is real work — it requires a YAML-to-node translation layer that doesn't exist yet.

A `TODO(FR50)` comment marks the spot. The infrastructure is in place. The gap is well-understood and bounded.

**Mary would say:** *"FR50 is 90% delivered. The last 10% is the part where the YAML actually drives the runtime instead of documenting it. That's the difference between 'defined in YAML' and 'described in YAML.' We shipped 'described.' We need to ship 'defined.'"*

## THE THINGS THAT MADE US WINCE

**The `pkg/dag` constraint.** "Do NOT modify pkg/dag" meant retry logic had to live in the orchestrator layer. `wrapWithRetry` sets `MaxRetries=0` on the node to prevent the DAG engine from *also* retrying the already-retrying Run closure. It works. It's tested. But it's conceptually weird: the DAG engine has built-in retry support that we deliberately disabled because we needed richer error collection than it provides.

**Scope refresh propagation.** The rewriter was removed in Epic 8. That change had to be tracked through Stories 4-1 (skill count: 5 -> 4), 4-2 (DAG layers: 4 -> 3), and 4-3 (conditional skip AC: N/A). Each story had stale references. They were caught, but the manual propagation is the kind of thing that breaks silently when you're moving fast.

**Go's `//go:embed` forbids `..` in paths.** Can't embed `../../skills/doctor/format-detector.skill.yaml` from `internal/doctor/`. Had to copy all 5 YAML files to `internal/doctor/specs/` and guard with `TestEmbedSync`. Annoying but unavoidable.

**Double-parse.** `analyzeFile()` parses the agent file once (for cache key computation and early error handling), then the DAG's format-detector node parses the same content again. Two full parse passes on every non-cached call. Deferred as a minor inefficiency because the parse is fast (~1ms), but Winston would call it "a code smell wearing a performance hat."
