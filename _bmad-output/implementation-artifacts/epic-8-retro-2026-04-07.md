## Headline Finding: Epic 8 Was Unintentional Bench-Prerequisite Work

The dominant insight of this retrospective: **Epic 8 was reproducibility infrastructure for InstructionBench (Epic 5), even though the team did not frame it that way at the time.**

Epic 8 was added to the backlog "from bench learnings" without a clear PRD scoping. It looked like AGENTS.md scaffolding. The actual change was deeper: Story 8.1 re-architected `forgent doctor --fix` from an LLM-driven rewrite into a deterministic scaffold. The `internal/doctor/rewrite/` package became dead code. The new `--fix` is reproducible (same input → same output), which is the *necessary* condition for Epic 5's runtime-vs-text experiment to be measurable.

Without Epic 8, every InstructionBench run on doctor's `--fix` would have produced different outputs and the bench would have been noise. With Epic 8, the bench is straightforward.

**This reframes the drift discussion from earlier the same day** (party-mode session that produced `sprint-change-proposal-2026-04-07.md`). The original framing was "Epic 7 and 8 were vision-defensible bonus work that delayed the keystone." The corrected framing after this retro is: **Epic 7 was opportunistic adjacent value (still defensible), but Epic 8 turns out to have been unintentional prerequisite work for Epic 5 — the team was *circling* Epic 5 (as Mary predicted in party mode) and the artifact that emerged was a reproducibility prerequisite they needed.**

Future-Guillaume reading this in three months should understand that the deterministic `--fix` exists *because* the LLM rewrite couldn't be benchmarked, not because LLM rewrite was a bad idea on its own merits. If anyone proposes re-introducing LLM rewrite, they should first answer: "How will this preserve InstructionBench reproducibility?"

## Process Finding: Review Gate Regression

Epic 7 retro (2026-03-31) celebrated "first epic with 100% review gate compliance" — 6/6 stories went through `in-progress → review → 3-layer code review → done`. This was the headline win of Epic 7 after 3 consecutive epics of review-gate violations.

**Epic 8 regressed.** The 3 stories shipped in 2 commits over ~17 hours with no per-story 3-layer review artifacts visible. The code quality appears acceptable (28 new tests, clean compile, all packages passing) and Guillaume self-reviewed as he went, but the **discipline** Epic 7 established was not sustained.

This is a real risk going into Epic 4 because Story 4.2 has an equivalence-test acceptance criterion (`recommendations match exactly: same issues, same categories, same confidence levels, same citations`) where a subtle bug could pass silent self-review and break the keystone claim that doctor proves the runtime works.

**Action Item #1 below restores the review gate as non-negotiable for Epic 4.**
